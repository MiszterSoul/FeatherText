A lightweight, free, framework-independent rich-text editor focused on speed, clarity, and practical customization.

Enhance a textarea with a ready-made toolbar, sixteen themes, HTML/source editing, and a direct runtime API. Decorative effects default to fancy: false and can be changed live with setFancy().

Product contract

Useful today. Honest about tomorrow.

Current source behavior and planned work are deliberately separated. A roadmap label never means “already shipped.”

✓ Current source

Ready-made editing essentials

  • Textarea contractGenerated UI keeps the original value in sync for forms.
  • Configurable toolbarFormatting, links, media embeds, tables, lists, colors, history, and modes.
  • Visual + source modesLine numbers, lightweight coloring, wrapping, indentation, and pairs.
  • Sixteen themes + autoNamed tokens and a custom theme-object path.
  • Direct HTML APIGet, set, clear, focus, theme, toolbar, lifecycle, and paste hooks.
  • Generated formatsBrowser global, ESM, CJS, and CSS outputs.

→ Limits and evidence scope

Boundaries remain explicit

  • Limited sanitizationThe conservative helper is not a complete sanitizer or authorization boundary.
  • Collaboration and revisionsNo CRDT, comments, track changes, or history service.
  • Uploads and storageApplications provide upload handling; FeatherText is not a file host or persistence service.
  • Exact browser evidenceAutomated versioned runs are evidence, not a blanket compatibility promise.
  • WCAG or screen-reader claimAutomated axe checks do not establish conformance or manual assistive-technology results.
  • Lighthouse scoreNo Lighthouse result is claimed.

A narrow abstraction

Textarea in. HTML out.

FeatherText keeps a direct model: a host textarea, generated editing UI, and HTML synchronized back to application code. That is a feature when it matches the job—and a boundary when it does not.

Small integration surface

Start with generated assets.

Build the repository first. npm and CDN instructions should be treated as post-publish until the registry package is verified. See the basic example or exercise live methods in the runtime API example.

index.htmlcurrent global build 
<link rel="stylesheet" href="./dist/feathertext.css">
<textarea id="editor" name="content"></textarea>
<script src="./dist/feathertext.min.js"></script>
<script>
  const [editor] = FeatherText.init("#editor", {
    theme: "auto",
    fancy: false, // the default; opt in to decorative effects
    sanitizePaste: true,
    toolbar: ["format", "bold", "italic", "link", "|", "ul", "ol", "|", "source"]
  });
</script>
